# LoR NX 

Library of Ruina's Nintendo Switch version, running natively on your iPhone as a Mach-O exec. Fork of [NX Native](https://github.com/seedds/nxnative)

## Features 

LoR NX Features several mods that aim to fix Arc Systemworks' shortcomings with the Switch Port, as well as several QoL life mods every Ruina player knows and uses 

Featured Mods: 
* No grind 
* PattyOptimization 
* Map Optimizations: Yesod
* Targetable Mass Attacks 
* Speed Dice Fix 
* Custom Speed Dices 

A full list of all available mods can be seen [here](mods/)

Several mods have been taken and ported from [Library of Ruina's Steam Workshop](https://steamcommunity.com/app/1256670/workshop/) and [NexusMods](https://www.nexusmods.com/games/libraryofruina), credits are given to their respective authors

## Installation 

Download **nxnative.ipa** and **nxnative-shaders.zip** from the [releases tab](../../releases/latest). The romfs.img is available to download in the [Discord](https://discord.gg/nRmztE2unw)

Install the .ipa with your preferred Sideloading service of choice, [SideStore is recommended](https://sidestore.io/)

Follow the README instructions inside **nxnative-shaders.zip**


##  Requirements 

A desktop environment for initial setup, if unavailable, see [SideInstaller](https://sideinstaller.net/)

System requirements: A14 chipset or higher, M1 chipset or later 

The game **will not** boot up on lower chipsets, NVN needs Metal 4 to work, which isn’t supported on older models
